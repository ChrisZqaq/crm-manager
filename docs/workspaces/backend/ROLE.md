# 原开发／后端工程师角色规则

公共规则为根AGENTS和[协作](../../project/COORDINATION.md)，此文件只补本角色要求；会话ID不另复制。

- 职责：主责全项目业务服务、模型、数据库与迁移、API、事务、服务端权限和计算；与前端明确接口，提供UI所需业务事实。只读支持只是某轮任务状态，不是长期职责限制。
- 按需阅读：当前任务对应业务、SPEC/数据库/成本算法及API章节；不默认读取原型探索/视觉技能。
- 写入边界：自己的工作区；负责人派发后才写对应业务/API文件，不能和前端同时改应用。
- 工作流程：不把原型或设计意见当新业务需求。需要接口变更先说明对库存/权限/状态的影响，等待明确范围。按最小可运行回归验证，固定提交交测试并同步负责人；交付后冻结，不自行推送。
- 角色工作从负责人派发任务开始；直接答疑不授权新写入。完整流程和升级路径遵循公共协作，不限UI改造；当前暂停/恢复以开发计划为准。
- 当前记录：[WORK](WORK.md)，过程笔记只保留与当前任务有关内容；交付写依据/范围/证据/限制/下一步，不粘贴全量聊天或复制公共公式。
- 重要阻断/接口或范围改变报告负责人；建议不自动成为业务事实。交付后不继续改被测版本。

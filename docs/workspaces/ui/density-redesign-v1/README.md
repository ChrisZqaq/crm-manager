## 设计方向及参考

用三页代表稿展示通用文字/控件/表格/留白及两种配色。正文16px，卡片标题18px、内容15px、图表桌面刻度14px，表单标签15px/输入16px；相对于当前常见卡标题15px/内容12px按用户“加大3字号”先解释为增加3 CSS px，最终视觉由用户确认，不猜中文印刷字号制。数字保持突出层级，不整体缩字。中文系统字体，品牌靛蓝/原白底Logo保留。

参考[Sales CRM Platform](https://uupm.cc/demo/sales-crm-platform)：用agent-reach/Jina实际读取到产品展示/数据管线分组内容；页面属于营销展示，未复制Hero、认证徽章、评价或AI功能到后台。浏览器该远端页面截图持续超时，不能称已经完成视觉克隆。UI-UX-Pro-Max两次design-system搜索仍返回营销页面结构，不采用该结构/推荐蓝绿品牌或英文字体；本稿采用其内置可读字号/可见标签/表格分组原则及用户截图，不冒称匹配到完整可用后台设计系统。MiniMax图像工具未配置，用户附件直接由原生视觉读取，未安装技能/MCP。

## 具体改动

- 工作台：八卡同高182px、4列桌面/2列中间宽度/1列手机；全部竖分隔112px，左指标水平及垂直居中。标题18px，预览15px，普通数字36px；销售/增长30px（宽屏/手机34px）。减弱大阴影，统一内距16px/卡距14px。Top3长名省略且可查看完整资料，金额独立。样图为销售角色，老板末卡业务映射仍沿用现有规则。
- 客户：去掉右侧常驻空分栏，表格外框与筛选框全宽对齐；搜索框桌面320px，控件42px高/按钮44px高，不再拉满整行。表格正文16px/行约56px，保留既有客户、联系方式、公司、发票抬头、负责人、状态、操作。空态放表头下，与全宽列表一致。
- 客户弹窗：两列相称字段，42px高，文字16px；保持原已批详情/编辑方向。这里只展示四个字段的尺寸关系，不是删除实际客户/地址/开票字段的业务批准。
- 库存：删除用户框出的仓库×SKU记录和全局低库存摘要两卡整排；保留筛选、按单位统计及明细/导出入口。按单位统计压成两排紧凑区域，原字段及单位语义保留；未知权限/成本/库存公式不变。短选择框170px、SKU280px，减少无意义空白。
- 手机长表只在表格内部滚动，正文不缩为小字、页面不横溢；中间宽度八卡统一两列，避免上下排断点不一致造成订单竖条。
- 配色：默认背景米色`#F4F1E9`/卡片浅米`#FFFDF7`；绿版背景`#E9F0E5`/卡片`#F7FAF2`。品牌色`#302C6C`不变。配色按钮在候选页底，用于比较；实际偏好入口/是否保存尚未形成实施合同，不添加真实设置或存储。

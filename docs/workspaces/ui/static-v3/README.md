2. 库存查询：可售/订单占用/客户预留/破损摘要，商品或SKU/IP/仓库/状态筛选，导出Excel；商品、SKU、单位、仓库、在库、订单占用、客户预留、可售、单位成本、库存状态表。商品档案：IP分类、商品搜索与类型/状态筛选；商品资料与独立SKU分开呈现，语言/官方编号为商品资料，不暗示单位自动换算；小型通用包装缩略图。

## 这一版的变化

- 同页三阶段：客户与交付→添加商品→核对订单；采购对应仓库供应商→录入实收→核对入库。当前展开、已填摘要可修改、待完成弱化。滚动时保留步骤条；只缺真实确认前提时禁用核对步骤，不禁止先选品。
- 当前主按钮随阶段变化；核对在同页展示，手机金额与返回/确认固定在底部。使用短标签、边框、完成标记代替长解释；错误、暂停原因仍用明确文字。
- 200ms步骤淡入/轻位移、220ms新增行反馈、按钮按压反馈；prefers-reduced-motion覆盖动画/过渡，脚本滚动也读取该偏好。没有新增动效依赖、框架或设置平台。
- 客户/商品独立可编辑，多SKU同区连续搜索加行。返回不清空输入；跨阶段错误链接可展开相应步骤并聚焦字段。合成示例重新载入时清理旧错误。
- 每行选定仓/SKU后显示可售及当前成本/单位，不能编辑成本或代猜成交价。未出库详情不提前显示毛利提成；实际出库后的示例区只演示出现时点，不代表已接后端新合同。到账核对与提成仍分别确认，原权限/客户地址/收货条件未删。

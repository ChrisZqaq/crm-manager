## 业务与接入边界

- 老板他人销售订单仅核对/审批/有权限只读，不代登记收款或代发货；老板本人销售仍有其实际销售职责。服务端按单边界与页面呈现需共同满足；不能只隐藏表单。现有代建/管理能力是否与此冲突，由负责人、后端依据最新用户决定收口，不由前端猜权限。
- 未核对可发货、收款问题未发货则暂停、已发货不倒退、补正不自动解除暂停等规则保持。不能将三个Tab实现成新的串行订单状态机。
- 提成及其它审核退回/重提没有确认的路径，不新增按钮/状态/API，不以“保原额”替代退回；集中未决交负责人安排。已定义收款补正沿现合同。
- 本交付无新统计口径、业务表、权限组、金额算法或上传方案；必要接口差异先与后端核实并报负责人。加载/失败/撤权/重复提交及幂等保护沿真实服务实现。

## 设计

- 靛蓝品牌区融入原Logo、橙金短线；桌面左品牌右表单，手机上品牌下表单。浅底、白面、系统中文字体，沿用已批系统配色和控件圆角。
- 账号/密码标签持续显示，48px控件，主按钮为登录；密码默认隐藏，可切显隐，按钮有可访问名称和状态。支持密码管理器、复制粘贴与键盘焦点。
- 账号/密码空值提示放字段旁并聚焦首个错误。原型不提交、不存储、不验证账号；演示反馈不能代替真实登录结果。
- 将来接入须保留现有登录、会话、CSRF及失败反馈，不能为设计增加认证业务。预览说明文字不进入正式页面。未增加注册、密码重置、第三方登录或新的角色选择流程。

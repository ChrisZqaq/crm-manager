2026-10-13。用户直接来源/范围见[UI WORK唯一审批栏](../WORK.md)。依据现有冻结稿与已验收三页tokens，不另做原型；前端核对负责人公共计划的唯一写入窗口/基线后实施。此新范围替代原三页交付中未列页不推广限制，仅覆盖本次指定页。

## 共用视觉基准

- 默认米色：页面#F4F1E9、卡#FFFDF7、正文#2D2D3F、辅助#6F6B7E；柔和绿：页面#E9F0E5、卡#F7FAF2、正文#28362E、辅助#606E62；品牌#302C6C、红字#B64148及白底Logo保持。表格头/边线继承现有主题tokens，不留旧纯白孤岛。
- 正文/输入/选择/表格数据16px；标签/表头/辅助15px；分组标题18px；页面主标题28px（窄屏沿既有适配）。这不是所有元素机械增加3px，指标等特殊层级沿现已有实现。
- 单行输入/选择基准42px、主要按钮44px，短字段用现有相称宽度和换行，不全行拉伸、不把所有字段固定成一种宽。多行文本/多选/inline formset自然高度，不压成42px；checkbox/radio/日期及上传控件保留原生行为/点击可达。错误正文可读且完整，不因密度隐藏说明或裁切字段。
- 卡/表单留白沿已定稿紧凑内距和内容自然高度，保留真实多行数据/业务分组；不引入新卡片、不改变页面信息架构。表格必要内部横滚，根页面不溢出，字体不为容纳全部列缩小。
- 主题入口和localStorage偏好复用既有机制，读写异常不能中断导航/页面初始化；新指定页/Admin继承同一选择，不新API/数据库/账号设置。

## Admin的最小接入

通过既有Admin基础模板/样式层继承主题tokens、正文/标题/字段/控件/表格和主题入口，复用现有偏好helper。Django原按钮/权限/表单错误/关联对象弹窗、inline/delete/history入口、面包屑及分页保持可用；既有中文品牌与侧栏保持。不同DOM结构用Admin对应选择器映射同token，避免复制七份CSS或强行套业务页DOM。不得改登录品牌/认证页，Django权限/模型metadata/原控件语义不变。

已过面包屑桌面/手机避菜单位置属于既有布局，字体放大后若自然换行需保证可见/不盖标题，不能顺带重做布局。原深色导航维持品牌，内容面/筛选/结果/fieldset/弹窗用当前主题；有语义状态色保留可读性，不全色漂成背景。

## 固定后定向核对

前端给指定七类真实合成页及必要对应常用表单的实际字体/背景/控件/两主题/主题跨页保持与桌面手机根宽证据，说明实际URL/角色/未测项。UI看独立固定版实际页面，不把模板字符串、HTTP200、旧三页图当推广验收。Admin需实际有权限账号查看列表与add/change/导航，未提交业务保存也可检查保存控件可达；真实写/权限回归由QA按改动风险负责。

仅样式推广，若需要新增布局/功能/删字段或其它未列页面，报负责人并由UI判断是否需要用户新决定；业务未知不上色过程中自行猜。固定后停止应用写入，负责人整合验收后决定发布，UI批准范围不等于实施已通过/已上线。

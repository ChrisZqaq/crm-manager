# UAT-FIX-1104 最小UI修复校准

2026-11-04；依据负责人派发和 `docs/project/UAT_REVIEW_20261104.md` 最新修复授权，公共计划基线bb1f5d6（应用5bc00f0）。只读现有模板/样式，不是新候选或新视觉验收。前端为唯一应用写入者，UI只写本工作区。

## 实施要点

1. **漏页主题沿用原tokens**：`base.html`现html/body的page-expanded与主题选择器条件须一致补漏，不只补背景色。核商品目录/导入、客户独立新建编辑和非收款报表等实际路由；沿用app.css既有canvas/surface/ink/muted/line及米/绿切换，不新建第三套变量或全局覆盖登录。当前获批canvas/surface米色#F4F1E9/#FFFDF7、绿色#E9F0E5/#F7FAF2；正文16、标题28/手机22、辅助15取既有规则。控件和按钮沿所属现组件尺寸，不借本任务统一放大所有页面；保既有需44px的交互目标。弹窗/下拉面板/错误背景也用tokens，不出现一块冷灰旧样式。
2. **客户表单明确grid**：`customer_form.html #customer-form`沿既有`.form-grid`两列minmax(0,1fr)、align-items:start，长textarea不拉高旁边单行input/select。负责人/地址fieldset、反馈及保存操作横跨整行；地址内部复用既有地址分组，390单列。标签在上、控件撑满本格，避免label一行里文本挤输入；保所有字段/选填和原地址规则。客户列表及既有原生详情/编辑弹窗不另换交互。
3. **调整按业务小节独立grid**：`adjustments.html`拆箱、赠送、破损/盘点/纠错各自使用局部表单栅格，不能把整个legacy-content设成一张大网格。来源/目标相同字段成组对齐；SKU搜索较宽、数量较窄，原因与提交行跨列，动态新增行保持同一列序；窄屏单列。只排版，不交换来源/目标语义或新增审批步骤。父grid item/table容器min-width:0，hidden字段仍display:none且无占位。
4. **商品空详情不占栏**：`catalog.html`默认无选中商品、关闭详情、筛选淘汰当前选择及空结果时，详情与其grid列一起退出布局，列表利用可用宽度；仅隐藏aside但保留split-layout第二列是不完整修复。选中后仍使用原有桌面详情栏、手机详情/返回列表、未保存输入保护，关闭回触发行与原筛选页码；不转成新模态/新页面或自动选首项来填空白。加载错误不保留另一商品的误导详情。
5. **目录主表减少展开式摘要**：现有skuCodes拼全串、inventory逐SKU×仓库拼全文，主表只需可辨商品/IP/语言、规格概览、状态及必要既有信息；SKU列用匹配规格数量或有限前几项+“另N项”，库存不逐仓铺陈，完整SKU/单位/包型/别名/状态/仓库信息保在现详情。概览不省略到只剩无法区分的同名商品；详情中SKU号+单位+包型/别名仍能辨盒/包等规格，未知/空值保持现占位。主表统计“当前筛选匹配SKU”还是“全商品SKU”必须忠实API实际返回，不伪装总数。混单位库存不跨单位相加，也不因密度调整删受权限控制的资料能力。
6. **保现分页/筛选**：当前目录page_size=50且上下页存在，不新增分页/虚拟列表；SKU状态仍启用/停用筛选，档案可查看停用SKU，下单选品规则不扩。主表有长文本可正常受控换行/有限摘要，不设统一高卡填空或每行等高遮内容。
7. **报表在真实容器内横滚**：`report.html`非收款data-card内的table-wrap与现legacy直接子选择器不匹配；命中实际嵌套容器，min-width:0/max-width:100%/overflow-x:auto，父grid也可收缩。保所有财务列/有效第3位/导出与原分页。长表右端字段可用触摸和键盘到达，根页面不能跟着横移；必要时给滚动区可聚焦与明确名称，不给每个普通单元格额外Tab。
8. **其它批准交互沿现模式**：收款无图/上传中错误就在当前表单、清楚标所需动作并可聚焦，失败保输入，已有关联凭证不强迫重传；客户转交成功就近可见且更新负责人。403给返回工作台但保403状态/权限；离开提醒仅未保存输入且成功不误拦，不存本地业务草稿。SKU局部查找沿现API、显示加载/无结果/失败及保选值，不开新搜索框架。

## 固定后仅本轮1440/390观察点

- QA固定源码/CSS与既有合成样本交接后，实际截图及DOM：漏页两主题背景/文字/输入/表面一致；不凭模板或HTTP200宣称通过。
- 客户含长联系方式/地址与调整动态行：单行控件同顶、不被textarea拉伸，窄屏一列/可聚焦、隐藏无空白/无校验幽灵，页面根clientWidth=scrollWidth。
- 目录默认/选中/关闭/筛选失配/空结果，主列表宽度随详情显隐正确变化；不全铺多SKU×多仓；现50分页仍在，详情规格可辨且手机可返回原列表，不造新数据验证。
- 非收款长报表：实际内部scrollWidth>clientWidth时，右端列可达且根不横溢，财务列和值未丢；数字精度规则不变。
- 其它本轮反馈按QA负责真实提交/失败/上传中/离开等合成证据分工，UI只记录实际观察项；不重审旧全站，不将源码建议当新界面批准或技术验收。

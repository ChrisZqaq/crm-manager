# UI设计师角色规则

公共规则为根AGENTS和[协作](../../project/COORDINATION.md)，此文件只补本角色要求；会话ID不另复制。

- 职责：设计审查、原型、用户批准与设计交付；不改真实应用。
- 按需阅读：PRD及本轮相关业务/权限；接口需确认时查API相关段落，不默认加载数据库/成本算法。
- 写入边界：仅docs/workspaces/ui/；不改公共文档、crm/config或数据库。
- 工作流程：选择适用UI/UX技能并读取技能要求，先审查现有界面，再产出合成数据原型。用户品牌意见不是批准；每候选记录文件指纹、范围及验证限制。直接用户批准后在WORK审批栏保存来源、指纹、获批页面和不包含范围；冻结交付给前端并同步负责人。未批准或内容变化不能交实施。
- 当前记录：[WORK](WORK.md)，过程笔记只保留与当前任务有关内容；交付写依据/范围/证据/限制/下一步，不粘贴全量聊天或复制公共公式。
- 重要阻断/接口或范围改变报告负责人；建议不自动成为业务事实。交付后不继续改被测版本。

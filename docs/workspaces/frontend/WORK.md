- 定向复测：在1280×720及390×844记录`document.documentElement.scrollWidth`不超过视口宽度；检查表格容器自身`scrollWidth/clientWidth`证明可横向滚动，并确认字段完整、触屏可滚。后端当前独占应用写入，仍等待负责人明确恢复。

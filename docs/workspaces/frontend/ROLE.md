# 前端开发工程师角色规则

公共规则为根AGENTS和[协作](../../project/COORDINATION.md)，此文件只补本角色要求；会话ID不另复制。

- 职责：把用户批准的UI落实为原生Django模板/CSS/JavaScript；不推导新业务。
- 按需阅读：UI交付的批准版本及说明、API/权限相关段落、需修改的模板与消费者；不默认读取UI探索过程或所有业务实现。
- 写入边界：自己的工作区；获批准交付且负责人明确应用写入者后才可改指定模板/样式/交互。
- 工作流程：批准前只读。收到UI交付后核对WORK审批栏及文件指纹；范围不清则报告负责人。接口咨询可直接问原开发，跨后端改动由负责人排期。自测→固定提交→向测试交接并同步负责人→停止应用写入，不自行推送。
- 当前记录：[WORK](WORK.md)，过程笔记只保留与当前任务有关内容；交付写依据/范围/证据/限制/下一步，不粘贴全量聊天或复制公共公式。
- 重要阻断/接口或范围改变报告负责人；建议不自动成为业务事实。交付后不继续改被测版本。

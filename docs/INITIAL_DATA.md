# 期初盘点模板与 Excel 导出

## 数据依据与切换范围

- 期初以用户按本模板重新盘点填写的数据为准，不以银豹导出及其字段分类作为导入规则。
- 旧业务和旧订单不导入；从新系统上线时录入的实际在库库存、成本开始计算后续业务与统计。
- 货物仍在仓库的预留、囤货和破损数量按实际情况登记，不恢复旧订单或旧提成。
- 期初导入建立库存与成本起点，不伪造采购交易，不把旧库存计成上线后的采购或销量。
- 实际盘点文件含业务数据，不提交 Git；仓库只保留空白模板与说明。

## 商品档案：一行一个 SKU

使用 [期初盘点模板.xlsx](templates/期初盘点模板.xlsx)。表名和列名保持不变，第1行为表头、第2行开始填写。

| 序号 | 列名 | 填写说明 |
| --- | --- | --- |
| 1 | 商品内部编号 | 同一SKU唯一稳定；宝可梦PK-前缀，符文战场RB-前缀；箱、盒、包分别编号 |
| 2 | IP品牌 | 必填 |
| 3 | 商品类型 | 卡牌／周边 |
| 4 | 系列 | 选填，一层系列 |
| 5 | 产品名 | 必填 |
| 6 | 产品别名 | 选填，多个用中文分号“；”分隔 |
| 7 | 语言版本 | 区分简中、日文等，不能猜测；周边可空 |
| 8 | 官方编号 | 不作为内部唯一标识 |
| 9 | 箱规格 | 可选文本，例如20盒/箱、40盒/箱，仅作说明 |
| 10 | 包规格 | 可选文本，例如5张/包、20张/包、6张/包，仅作说明 |
| 11 | 包类型 | 肥包／瘦包／留空，与包规格分开 |
| 12 | 售卖单位 | 箱、盒、包、个、套等实际单位 |
| 13 | 包装条码 | 对应具体包装的真实条码，用文本保存 |
| 14 | 规格别名 | 选填，多个用中文分号“；”分隔 |

- 不再保存参考售价，销售订单人工填写成交价。
- 序号位数、其他IP前缀及自动生成方式尚未确定；模板先手填，不擅自设定。
- 箱规格、包规格不触发数量换算，不扩展自动拆箱功能。
- 同一产品在多行重复的信息保持一致；导入前核对映射，不仅按名字跨语言合并。

## 期初库存：一行一个仓库＋SKU

| 序号 | 列名 | 填写说明 |
| --- | --- | --- |
| 1 | 仓库名 | 必填，同一仓库保持一致 |
| 2 | 仓库地址 | 必填，同一仓库保持一致 |
| 3 | 商品内部编号 | 必须关联商品档案已有编号 |
| 4 | 实际在库数量 | 非负整数，包括预留、囤货和破损 |
| 5 | 单位成本 | 对应该仓库及SKU售卖单位，最多3位小数；未知留空待补，不用零代替 |
| 6 | 客户预留数量 | 非负整数，无则填0 |
| 7 | 囤货数量 | 非负整数，无则填0 |
| 8 | 囤货原因 | 有囤货数量时填写 |
| 9 | 破损数量 | 非负整数，无则填0 |
| 10 | 备注 | 选填 |

- 同一仓库＋商品内部编号不重复；同一SKU可以在多个仓库分别填写。
- 预留、囤货、破损互不重复，合计不能超过在库数量。
- 可售数量及期初库存成本金额由系统计算，不增加模板列。
- 各SKU数量按自己的单位记录，不把箱、盒、包直接相加。
- 空行忽略；缺成本、编号不匹配等问题必须在正式导入前解决。

## 模板和导入校验

- 两张表分别为商品档案、期初库存；表头冻结并支持筛选，编号和条码为文本，成本显示3位小数。
- 商品类型、包类型及库存商品编号有下拉；基础校验覆盖商品编号重复、非负整数数量、受限数量合计、非负且最多3位的成本。
- 校验预设第2至5001行，前200行提供空白格式；超过时扩展模板，不代表系统数量上限。
- 留空和复制粘贴可能绕过Excel校验，正式导入须复核必填、唯一性、仓库信息一致、编号关联、数量和成本。
- 切换日期、盘点至上线之间出入库如何对齐在上线计划确认，不假设该期间没有业务。

## Excel 导出

- 第一版只导出库存、销售、收款核对、提成四张报表的当前筛选结果，格式为.xlsx。
- 导出遵守账号查看范围，金额保持3位精度，编号和条码用文本。
- 不增加任意数据库表导出、批量截图下载或历史数据仓库。

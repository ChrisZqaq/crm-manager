# 期初盘点模板与 Excel 导出

## 数据依据与切换范围

- 期初以用户按本模板重新盘点填写的数据为准，不以银豹导出及其字段分类作为导入规则。
- 旧业务和旧订单不导入；从新系统上线时录入的实际在库库存、成本开始计算后续业务与统计。
- 货物仍在仓库的预留、囤货和破损数量按实际情况登记，不恢复旧订单或旧提成。
- 期初导入建立库存与成本起点，不伪造采购交易，不把旧库存计成上线后的采购或销量。
- 已确认正式期初一次整批确认入账，涵盖所有仓库；确认前可反复上传校验预览、不增库存。成功后关闭期初库存导入口，不允许重复、覆盖或追加，重复点击不重复入账；测试环境可反复试导，与正式库存隔离。上线后采购走正常入库，期初错误须核对纠错、不靠重传表格覆盖。
- 2026-10-09入口调整：期初只在管理入口提供，不作为日常常驻导航；老板／管理员可在尚未入账时关闭或重新开启导入，关闭在服务端同时阻止预览及确认。成功入账后永久禁止重新导入，开关不重置opening_completed，不恢复覆盖/追加能力；导入操作本身仍遵守原授权范围。
- 已确认期初纠错沿用采购纠错规则：未影响后续业务由仓管修正对应期初记录并更新库存成本；有影响时仓管提交库存、订单成本及提成变化预览，老板确认后整体重算。保留前后值、原因及必要审批，不允许负库存；不重导、不增加独立审批流程、不将期初改为采购单。
- 实际盘点文件含业务数据，不提交 Git；仓库只保留空白模板与说明。

## 商品档案：一行一个 SKU

使用 [期初盘点模板.xlsx](../templates/期初盘点模板.xlsx)。表名和列名保持不变，第1行为表头、第2行开始填写。

| 序号 | 列名 | 填写说明 |
| --- | --- | --- |
| 1 | 商品内部编号 | 必填唯一；IP前缀＋至少4位流水号，如PK-0001、RB-0001，各IP独立编号；每SKU单独编号，箱盒包不共用编号 |
| 2 | IP品牌 | 必填 |
| 3 | 商品类型 | 仅三个选项：“补充包”“周边”“礼盒·预组”；最后一项合并 |
| 4 | 系列 | 选填，一层系列 |
| 5 | 产品名 | 必填 |
| 6 | 产品别名 | 选填，多个用中文分号“；”分隔 |
| 7 | 语言版本 | 补充包及礼盒·预组必填，明确填写简中、日文、英文等，不默认简中；周边可空；同产品各SKU保持一致 |
| 8 | 官方编号 | 不作为内部唯一标识 |
| 9 | 箱规格 | 可选文本，例如20盒/箱、40盒/箱，仅作说明 |
| 10 | 盒规格 | 选填文本，例如18包/中盒，仅作包装说明，不参与数量换算 |
| 11 | 包规格 | 可选文本，例如5张/包、20张/包、6张/包，仅作说明 |
| 12 | 包类型 | 肥包／瘦包／留空，与包规格分开 |
| 13 | 售卖单位 | 箱、盒、包、个、套等实际单位 |
| 14 | 包装条码 | 可空，真实包装条码用文本保存、保留前导零；重复时展示对应SKU并要求确认后才能导入 |
| 15 | 规格别名 | 选填，多个用中文分号“；”分隔 |

- 不再保存参考售价，销售订单人工填写成交价。
- 编号先人工填写，格式及唯一性由系统校验；至少4位序号，超过9999继续10000。编号使用后保持不变、停用不复用；其他IP前缀由用户指定，不自动猜测。
- 箱规格、盒规格、包规格不触发数量换算，不扩展自动拆箱功能。
- 2026-10-03确认：按IP品牌＋商品类型＋系列＋产品名＋语言版本＋官方编号一致识别同一产品候选，展示各SKU产品归属预览，由人员确认后导入；不只按名字合并，不做模糊归并。同产品多行别名等共有信息有冲突时提示核对，不静默覆盖。
- 产品归属只共享产品资料，箱盒包等SKU的编号、库存、占货及成本仍独立，不合并数量或自动换算；不增加模板产品编号列。

## 期初库存：一行一个仓库＋SKU

| 序号 | 列名 | 填写说明 |
| --- | --- | --- |
| 1 | 仓库名 | 必填，同一仓库保持一致 |
| 2 | 仓库地址 | 必填，同一仓库保持一致 |
| 3 | 商品内部编号 | 必须关联商品档案已有编号 |
| 4 | 实际在库数量 | 非负整数，包括预留、囤货和破损 |
| 5 | 单位成本 | 对应该仓库及SKU售卖单位，最多3位小数；未知留空待补，不用零代替 |
| 6 | 客户预留数量 | 非负整数，无则填0 |
| 7 | 囤货数量 | 非负整数，无则填0 |
| 8 | 囤货原因 | 有囤货数量时填写 |
| 9 | 破损数量 | 非负整数，无则填0 |
| 10 | 备注 | 选填 |

- 同一仓库＋商品内部编号不重复；同一SKU可以在多个仓库分别填写。
- 预留、囤货、破损互不重复，合计不能超过在库数量。
- 可售数量及期初库存成本金额由系统计算，不增加模板列。
- 各SKU数量按自己的单位记录，不把箱、盒、包直接相加。
- 空行忽略；缺成本、编号不匹配等问题必须在正式导入前解决。

## 模板和导入校验

- 两张表分别为商品档案、期初库存；表头冻结并支持筛选，编号和条码为文本，成本显示3位小数。
- 商品类型、包类型及库存商品编号有下拉；基础校验覆盖商品编号重复、非负整数数量、受限数量合计、非负且最多3位的成本。
- 校验预设第2至5001行，前200行提供空白格式；超过时扩展模板，不代表系统数量上限。
- 留空和复制粘贴可能绕过Excel校验，正式导入须复核必填、唯一性、仓库信息一致、编号关联、数量和成本。
- 2026-10-03确认上线安排盘点切换窗口，暂停各仓实际出入库；用户确保正式导入数据准确并对齐同一切换时点，导入核对后恢复业务。提前填写的表格不直接视为切换时点库存，不增加银豹同步或期间自动追差；具体上线日期及窗口长度另定。
- 开发测试使用合成数据。用户可选填少量商品及库存模板样例核对实际字段、搜索和导入，不作为开发前置条件；测试样例不计入正式库存，正式期初以切换时点核准的数据为准。

## Excel 导出

- 第一版只导出库存、销售、收款核对、提成四张报表的当前筛选结果，格式为.xlsx。
- 导出遵守账号查看范围，金额保持3位精度，编号和条码用文本。
- 不增加任意数据库表导出、批量截图下载或历史数据仓库。

2026-10-04模板更新：商品档案增加盒规格，现为15列；箱规格I列、盒规格J列、包规格K列，后续列顺延，期初库存表不变。请使用更新后的空白模板，不在旧列位置直接粘贴数据。

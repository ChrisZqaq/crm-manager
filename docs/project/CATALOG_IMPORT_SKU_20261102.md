# 商品独立导入与规格生成

任务：CATALOG-IMPORT-SKU-1102。用户2026-11-02明确要求先在Windows导入真实商品、暂不处理库存；产品资料共用，按包型及售卖规格自动生成SKU，提供Excel模板。

## 最小合同

- 模板：[商品批量导入模板-V1.xlsx](../templates/商品批量导入模板-V1.xlsx)。只读取“产品导入”和选填“规格补充”；“使用说明”“填写示例”不入档。空白数据行忽略，表头不能改，拒绝公式/非法值。
- 产品列：产品标识、IP、商品类型、系列、产品名、产品别名、语言版本、官方编号、包型组合、生成箱、生成盒、生成垃圾袋、生成包、其他售卖单位、发售日期、补充说明。
- 产品标识为本文件内唯一关联码，不是系统产品ID或官方编号。普通资料一次填写；语言/类型/IP遵守现有后台选项，不能猜新IP前缀或模糊归组。
- 包型组合为不区分/仅肥包/仅瘦包/肥包和瘦包；前四规格选是/否，空等否；其他单位以中文分号分隔。至少选一单位，按包型×实际选择的单位生成，不默认生成全部。垃圾袋为独立SKU，售卖单位沿现文本字段，不新建包装模型或库存换算。
- 规格补充列：产品标识、包类型、售卖单位、规格区分、SKU编号、规格别名、包装条码、包装长mm、包装宽mm、包装高mm、包装毛重g。只填需要补资料的组合，包类型为不区分/肥包/瘦包。空规格区分指默认组合；非空如大箱可在已选组合内另建SKU，区分保存在现规格别名，不新增持久规格层。
- 未指定SKU编号时按后台IP前缀流水自动分配；指定编号保留但冲突拒绝，不覆盖旧SKU。不同包装用对应条码，可空，重复条码沿既有人核规则。尺寸/毛重沿0020正数/空值合同，不能写数量或成本。

相同产品下肥瘦、单位和大箱等区别必须在已有SKU选择器明确展示，避免共同产品名使员工选错；只修必要消费者，不新增通用显示平台。图片不由Excel嵌图/路径/URL导入，导入后用已批准补充资料上传。

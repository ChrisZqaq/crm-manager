## 已确认规则

1. 业务订单号采用订单正式创建日（北京时间）加当天流水号，例如202610280001；每天从0001开始，生成后不变，取消不回收。内部数据库ID、业务操作序号及版本号继续各司其职，不作为对外订单号。
2. 操作成功留在同单最新详情，隐藏已完成操作并提示下一步；确认收货成功后返回待办。成功前禁用重复提交，失败保留输入；真实状态冲突须重新读取状态并给出可操作反馈，不能让用户反复点击旧按钮。
3. 用户未确认存在正式历史订单。此前“现有订单”问题仅指截图中的本机合成测试记录，不等于已查到正式订单；不据此授权删除测试单、迁移正式数据或补号。新字段落地前需核待迁移环境实际记录及保留范围；新空业务库无需迁移历史正式订单。

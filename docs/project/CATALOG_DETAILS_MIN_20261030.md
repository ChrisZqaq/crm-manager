# 商品补充资料最小开发

任务：CATALOG-DETAILS-MIN-1030。依据用户2026-10-30明确批准：单卡暂不做，其余补充资料最小范围开发。

## 范围

- 产品：选填发售日期、补充说明、单张主图。
- SKU：选填包装长/宽/高（毫米）、包装毛重（克）、单张包装图；条码复用已有字段。
- 数值未知为空，有值为有限正数，允许常见小数；三个尺寸独立选填，不新增单位切换或换算。
- 图片JPEG/PNG/WebP，每张不超过10MB，服务端校验真实内容；文件仍私有存储，读写遵守商品/SKU权限。每对象当前一张，支持补充、替换、清空；不混用收付款凭证业务记录。
- 新建可全部省略，已有商品可补充；页面复用现有样式，默认折叠“补充资料”，不挤进销售下单、首页或目录主表。
- 加法迁移，旧数据留空；不改变库存/成本/订单/提成、不重编号/改挂已有SKU，不强迫现有期初模板增加列。

## 不做

单卡/稀有度、运费估算、快递接入、包装数量换算、自动生成经营规格、多图图库、远程图片抓取/识别、参考表自动回填、批量图片导入或通用资料/资产平台。真实文件整理仍是独立任务，不将候选导入当本轮开发依赖。

## 交付顺序

后端唯一应用写入，最小字段/接口合同同步前端只读准备；后端固定后负责人切前端实施，随后QA定向验收、负责人复核。保留现有权限、事务/幂等及图片失败保护，不新增日志埋点。仅自有合成环境，不迁移Windows/云运行库或更改部署固定SHA。

验收：旧创建请求可用；选填/清空/非法数值和日期；真实格式/大小限制与图片替换失败不破坏原图；授权/撤权；新建及已有商品补充的实际浏览器操作和必要窄屏布局。不重跑无变化全套，不把HTTP200或源码断言当操作验收。

# CRM Manager

面向 TCG 经销与门店零售的进销存、客户维护系统。

核心目标：销售只登记一次，库存、收款核对、客户购买记录和提成都由同一笔业务记录产生，减少群消息、银豹、销售 Excel 与财务 Excel 之间的重复录入和对账。
